# Apachi Design Market (static)

Легкий статичний сайт для продажу графічних послуг, повністю готовий до деплою на GitHub Pages. Усі дані (заявки та галерея робіт) зберігаються у `localStorage` браузера, тому можна працювати без окремого бекенду.

## Можливості
- Головна сторінка з описом послуг і галереєю прикладів робіт.
- Форма заявки з прикріпленням референсів та чека (зберігаються як data URL у `localStorage`).
- Адмін-панель із простим паролем (`admin` за замовчуванням):
  - перегляд усіх заявок і деталей із вкладеними файлами;
  - оновлення статусів оплати та виконання;
  - додавання прикладів робіт у галерею.

## Як запустити локально
1. Відкрийте папку `docs/` у VS Code та використайте **Live Server** (або інший статичний сервер), або просто відкрийте `docs/index.html` у браузері.
2. Для входу в адмінку відкрийте `docs/admin.html` і введіть пароль `admin`.

## Деплой на GitHub Pages
1. Закомітьте репозиторій у гілку `main`.
2. У налаштуваннях репозиторію відкрийте **Settings → Pages**.
3. У полі **Source** оберіть `Deploy from a branch`, гілку `main`, папку `/docs` та збережіть.
4. Після публікації сайт буде доступний за посиланням GitHub Pages; усі дані зберігатимуться у `localStorage` відвідувачів.
5. Для прямого доступу за кореневою адресою додається кореневий `index.html`, який автоматично перенаправляє на `docs/index.html`.

## Налаштування
- **Пароль адміна**: змініть константу `ADMIN_PASSWORD` у `docs/admin.js` за потреби.
- **Початкові приклади робіт**: керуються з адмін-панелі; при першому запуску галерея порожня. Ви можете додати стартові приклади через адмінку або вручну змінити масив `seedExamples` у `docs/script.js`.

## Файлова структура
- `docs/index.html` — головна сторінка з формою заявки.
- `docs/admin.html` — адмін-панель.
- `docs/styles.css` — стилі.
- `docs/script.js` — логіка публічної сторінки (робота з галереєю та створенням заявок).
- `docs/admin.js` — логіка адмін-панелі (керування заявками та галереєю).

## Зауваження
- Дані зберігаються локально в браузері конкретного користувача і не синхронізуються між пристроями. Для спільної бази можна підключити будь-який зовнішній бекенд/API, замінивши збереження в `localStorage` на власні запити.
